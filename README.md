# Romantika Cosmetics Website

This repository contains a static website developed for **Romantika Cosmetics** as a semester project for the **Fundamentals of Web Technologies** module. The project demonstrates the practical application of web development concepts learned during the course, along with additional knowledge gained through self-learning resources such as **W3Schools** and **freeCodeCamp**. The website was developed using technologies including **HTML, CSS, JavaScript, and responsive web design**.

The website was designed to provide an attractive and user-friendly online presence for a cosmetics shop, showcasing its **product categories and brand information** through a modern web interface. As a foundational project, I plan to **continue improving and expanding this website in the future** by adding new features, enhancing its design, and applying the web development skills I gain throughout my studies.

## Project Information

* **Project Type:** Semester 01 Academic Project
* **Module:** Fundamentals of Web Technologies
* **Technologies:** HTML, CSS, JavaScript
* **Learning Resources:** W3Schools, freeCodeCamp
* **Website:** [Romantika Cosmetics](https://arham-aslam.github.io/romantika-t-1/)
